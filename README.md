# PCB Design Portfolio

A collection of printed circuit board (PCB) design projects developed using Altium Designer and other electronic design tools, showcasing my experience in hardware development, circuit design, component selection, PCB layout, and system integration.

## Projects

### 1. Junior Design PCB
**Tools:** Altium Designer

A PCB developed as part of a multidisciplinary engineering design project.

- Circuit design and schematic development.
- Component selection and footprint integration.
- PCB layout, component placement, and routing.
- Hardware integration and design considerations.

**Design previews:**
- 3D PCB renders
- PCB layout
- Schematic

### 2. PacBot Robotics PCB
**Tools:** Altium Designer

PCB design for a robotics platform, supporting electrical interfaces and integration with the robot's embedded control system.

- Hardware design for robotics applications.
- Power distribution and voltage regulation.
- Sensor and microcontroller interfacing.
- PCB layout, component placement, and routing.

**Design previews:**
- 3D PCB renders
- PCB layout
- Schematic

## Tools & Technologies

- **PCB Design:** Altium Designer
- **Circuit Design:** Schematic capture and component selection
- **Hardware Development:** PCB layout, routing, and design verification
- **Embedded Systems:** ESP32, STM32, sensor and communication interfaces
